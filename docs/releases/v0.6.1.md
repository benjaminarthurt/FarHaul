Far Haul 0.6.1 for Windows, in which the settings stop hiding things from you.

**Download** `FarHaul-windows-0.6.1.zip` under Assets below. Not the Source code files: those are GitHub's, and they contain exactly zero switches. Unzip it anywhere and run `FarHaul\FarHaul.exe`. Nothing is installed. Saves go in a `Far Haul saves` folder next to the exe, and saves from earlier versions still load.

**On first run** Windows SmartScreen may say "Windows protected your PC", because the exe is not code-signed. Choose **More info**, then **Run anyway**.

### Fixed
- The on/off settings (**Fullscreen**, **Vertical sync** and **Ship remote**) were checkboxes drawn in a shade of dark that matched the panel almost exactly. When off, they were very nearly invisible, which is a bold design choice for the switch that turns the remote on. They're now proper **ON** / **OFF** switches: amber when on, outlined when off.
- So, for anyone who went looking: **Settings → Ship remote → ON**, then open the address on your phone and type the code.

### Known limits
- 64-bit Windows (x86_64). ARM Surface devices run it through Windows' built-in emulation, wheezing slightly.
- Everything in 0.6.0's notes still applies, including the salvage crew's invoices.
