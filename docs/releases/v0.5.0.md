Far Haul 0.5.0 for Windows, in which the cockpit grows a second screen and you're allowed to leave the room.

**Download** `FarHaul-windows-0.5.0.zip` under Assets below. Not the Source code files: those are GitHub's, and they contain exactly zero remotes. Unzip it anywhere and run `FarHaul\FarHaul.exe`. Nothing is installed. Saves go in a `Far Haul saves` folder next to the exe, and saves from earlier versions still load.

**On first run** Windows SmartScreen may say "Windows protected your PC", because the exe is not code-signed. Choose **More info**, then **Run anyway**. If you switch the ship remote on, Windows will also ask once whether Far Haul may use the network: allow it on **private** networks. That's the one the remote needs.

### The ship remote
- Turn on **Ship remote** in Settings. It shows an address and a six-digit code. Open the address on a phone or tablet on the same Wi-Fi, type the code, and that device becomes a second cockpit screen.
- **The trip:** where you're going, a progress bar with the ship on it, distance to go, closing speed, and arrival time in real minutes at your current time compression. Now you know whether there's time for the kettle.
- **The map:** the same system chart and known space as **M** in the game, live, with the route, the ship and its nose and travel arrows. Drag to pan, pinch or tap to zoom.
- **The gauges:** speed, fuel, heat, hull and delta-v left, going red when it's time to worry.
- **The helm:** a throttle lever you drag, plus cut, brake, course hold, assist and time compression. Dock, traffic control and the tug only show up when the game would let you use them.
- The cockpit's own prompt runs along the bottom, so the remote nags you in exactly the same words.

### It follows the rules
- The remote presses the same buttons the keys do, with the same limits: x1 on the approach, course hold only within 5°, docking only in range. It's a second screen, not a cheat code.
- Steering stays at the helm. Point the ship first, then go and sit on the sofa.

### Kept on the local network
- Off until you switch it on. It only answers devices on your own network, and only after they've paired with the code.
- Five wrong codes and that device waits a minute. **New code** in Settings unpairs everything at once, in case you lent your phone to someone who likes buttons.
- The F10 menu shows the address and code too, for when the phone has wandered off.

### Also
- A test that sometimes failed for no good reason (surface work pay) now fails only for good reasons.

### Known limits
- 64-bit Windows (x86_64). ARM Surface devices run it through Windows' built-in emulation, wheezing slightly.
- The remote speaks plain HTTP on your home network. Fine for a sofa; don't open it to the internet.
- No steering from the remote, and no space walks, planets with air or crew yet. The sofa remains undefeated.
