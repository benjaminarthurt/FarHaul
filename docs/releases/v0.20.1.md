Far Haul 0.20.1 for Windows, in which one Vey controller clears her throat and tries again.

**Download** `FarHaul-windows-0.20.1.zip` under Assets below. Not the Source code files: those are GitHub's, and they're not on speaking terms with anyone. Unzip it anywhere and run `FarHaul\FarHaul.exe`. Nothing is installed. Saves go in a `Far Haul saves` folder next to the exe, and saves from earlier versions still load.

**On first run** Windows SmartScreen may say "Windows protected your PC", because the exe is not code-signed. Choose **More info**, then **Run anyway**.
