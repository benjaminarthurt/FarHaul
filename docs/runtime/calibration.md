# Runtime Calibration

Runtime simulation uses SI internally and one physical SCU standard. Cargo is constrained independently by mass and volume. Credits use fixed precision so finance can be audited.

The economic baseline is calibrated around an independent freight operator: ordinary competent hauling must cover financing, crew, insurance, maintenance and operating expense. High margins should come from specialization, urgency, risk, information advantage or efficient capital—not from every routine delivery being wildly profitable.

Canonical identity registries are mandatory for new runtime systems. Legacy overlapping datasets remain migration inputs only.
