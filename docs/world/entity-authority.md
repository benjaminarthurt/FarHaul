# World Identity and Authority

Far Haul separates **identity** from **mechanics**. A settlement has one stable identity record even when housing, transit, government, freight and history are stored in different datasets.

The canonical hierarchy is system → body → region → settlement → district → site, with organizations attached to the places where they operate. Specialized datasets reference those IDs rather than redefining the place.

Older files are retained during migration because they contain useful authored material, but they no longer define competing identities. New expansion should attach to authority records first.

This matters at large scale: procedural generation can create millions of ordinary records only if a city, factory or company cannot silently acquire three different IDs in three subsystems.
