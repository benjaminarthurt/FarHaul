# Simulation Integrity

Far Haul's world model uses accounting identities so depth remains coherent as data grows. Population must fit inside parent regions; production requires inputs, utilities and labor; inventories conserve material; freight cannot exceed capacity without backlog; housing and utilities expose shortages rather than silently serving impossible demand.

Procedural entities become persistent when interaction makes their identity matter. Promotion preserves their deterministic generated origin and adds mutable history, preventing the world from rerolling a familiar mechanic or neighborhood after the player leaves.

These rules are the bridge between authored lore and simulation. A dense world is not just many JSON records—it is a world whose records can all be true at the same time.
